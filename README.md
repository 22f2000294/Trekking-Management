# Trekking Management Application

A web-based application for managing trekking activities.

## Features

- User Management
- Trek Management
- Booking Management
- Staff Management
- Role Based Access (Admin, Trek Staff, Trekker)

## Technologies Used

- Flask
- SQLAlchemy
- SQLite
- Python

- Database Schema Created
- Relationships Defined
- Admin User Auto-Created
